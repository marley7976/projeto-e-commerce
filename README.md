# ⚽ Manto Sagrado Store - E-commerce de Camisas de Time

Projeto desenvolvido para a disciplina de Desenvolvimento Web (FATEC), com foco na criação de uma loja virtual de camisas de futebol utilizando HTML5, CSS3, Bootstrap 5 e JavaScript.

## 🔗 Link do Projeto
* **Repositório Oficial:** https://github.com

---

## 📋 Escopo e Entregas (Épicos)

### ✅ Epic 01: Organização, Documentação e Git-Flow
- [x] **Documentação do projeto:** Criação e estruturação deste `README.md`.
- [x] **Versionamento Git-Flow:** Configuração das branches principais (`main` e `develop`) e branches de funcionalidades (`feature/*`).
- [x] **Colaboração:** Adição do colega de equipe como colaborador no repositório do GitHub.
- [x] **Link do Projeto:** Publicação e vinculação do repositório oficial.

### 🚀 Epic 02: Desenvolvimento e Integração API
- [x] **Consumo de API:** Consulta de produtos via `fetch` e `async/await` limitados a **20 itens**.
- [x] **Catálogo e Busca:** Montagem dinâmica dos cards de camisas de time com filtro de pesquisa em tempo real.
- [x] **Estilização:** Layout responsivo estilizado com Bootstrap 5 e CSS customizado.
- [x] **Funcionalidades Extras:** Seletor de tamanhos (P ao GG), carrinho de compras interativo e janela de suporte.
